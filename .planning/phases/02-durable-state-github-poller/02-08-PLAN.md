    - OnClean ×5 consecutive restores BatchSize by doubling toward MaxBatch and resets the secondary streak on the first clean batch
    - Observe(cost=5, prs=20) updates the per-PR cost EWMA (initial 0.25, alpha 0.3) and stores Limit/Remaining/ResetAt

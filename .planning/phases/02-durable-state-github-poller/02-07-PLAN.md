<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| daemon → api.github.com | Bearer token crosses the network over TLS |
| gh config / keyring → daemon | Credential read from local files or a subprocess |
| GitHub response → client | Untrusted status, headers and body |
| env PR_RELAY_GITHUB_GRAPHQL_URL → client | Could redirect the token elsewhere |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-25 | Information disclosure | token handling | mitigate | Token only in memory; never logged, persisted or in error strings; only the source is reported |
| T-02-26 | Information disclosure | endpoint override | mitigate | New() accepts non-default endpoints only on loopback hosts |
| T-02-27 | Denial of service | gh keyring fallback | mitigate | exec.CommandContext with a 10s timeout |
| T-02-28 | Denial of service | oversized response | mitigate | io.LimitReader 16 MiB, 30s client timeout |
| T-02-29 | Spoofing | stale credential after re-login | mitigate | config.Reload before each resolution; re-resolve and retry once on 401 |
| T-02-30 | Denial of service (ban) | secondary limits | mitigate | Exact classification feeds the D-07 backoff in the scheduler |
</threat_model>

    `var ErrLocked = errors.New("store: state is in use by another pr-relay process")`, `var ErrNewerVersion = errors.New("store: state file was written by a newer pr-relay")`. `type Store struct { dir string; lock *flock.Flock; quarantinedPath string; quarantinedAt time.Time }`.

    `func Open(dir string) (*Store, *State, error)`: MkdirAll 0o700 + Chmod 0o700; flock.New(dir/state.lock), create the lock file with 0600 first via os.OpenFile so the mode is right; TryLock false → ErrLocked. Remove every `state.json.tmp-*` (filepath.Glob). Load: missing state.json → NewState. Otherwise call `migrate(version int, raw []byte) ([]byte, error)` (no-op for v1, documented hook), unmarshal the full State, a second-stage parse error also quarantines. Ensure nil maps become empty.

Wrap every error "store: save: <op>: %w". Never logs content.

    `func (s *Store) Quarantine() (path string, at time.Time)`, `func (s *Store) Dir() string`, `func (s *Store) Close() error` (Unlock and close the lock).

| Boundary | Description |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-18 | Information disclosure | state.json, state.lock | mitigate | Dir 0700, files 0600 (temp file chmod before write); state never contains the token |
| T-02-19 | Tampering | concurrent writers | mitigate | flock TryLock held for the store's lifetime; ErrLocked fails fast |
| T-02-20 | Denial of service | corrupt file | mitigate | Quarantine and continue (D-20) instead of crash-looping |
| T-02-21 | Tampering (downgrade wipe) | Load | mitigate | Version > known is refused, never quarantined |
| T-02-22 | Repudiation (lost events) | Save | mitigate | temp+fsync+rename+dir fsync; failure leaves the previous file loadable |
</threat_model>

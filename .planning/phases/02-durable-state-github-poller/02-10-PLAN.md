    - With zero subscriptions Run sleeps (30s cap) and sends no requests
    - A Subscribe while Run sleeps wakes it and the new PR is polled within one tick
    - Terminal PRs and PRs with no subscriptions are never polled
  </behavior>
  <action>
    scheduler.go: `const maxSleep = 30 * time.Second`, `const authRetry = 5 * time.Minute`. `func (e *Engine) Run(ctx context.Context) error` loop: now := time.Now(); under mu compute for every non-terminal PR record that has at least one subscription: base = BaseInterval(LastPollAt - RateAnchor, min, max); projected = budget.ProjectedPerHour(all bases); e.stretch = budget.Stretch(now, projected); jitter per PR derived deterministically from the PR key hash in [-0.1, 0] (stable, no rand); due = NextDue(...) (zero LastPollAt means due now). Select PRs with due <= now + CoalesceWindow(their effective interval), sorted by due. If none, sleep until the earliest due (capped at maxSleep) or wake or ctx. If auth is failed and now < authRetryAt, sleep. gate := budget.Gate(now, false); gate > 0 → sleep min(gate, maxSleep). Chunk the selection by budget.BatchSize and call pollRefs(ctx, chunk, false) for each chunk in order; after each, re-check the gate. Error handling from pollRefs: ghclient.ErrNoToken or ErrUnauthorized → set auth state NoToken/Unauthorized, authRetryAt = now + authRetry, call the fetcher's Invalidate if it implements `interface{ Invalidate() }`; success clears auth state to OK and records the token source if the fetcher implements `interface{ TokenSource() string }`. Sleep helper uses a time.Timer and selects on ctx.Done(), e.wake and the timer. Wall-clock time.Now() is recomputed every iteration (pitfall 11). Startup with many overdue PRs simply batches them (discretion: no spread; batches of 20 cost about 5 points).

    status.go: `type AuthState struct { State string; Source string; Since time.Time }` with State "ok", "no_token", "unauthorized", "unknown". `type Status struct { Auth AuthState; Limit, Remaining int; ResetAt time.Time; SpentLastHour int; Stretch float64; SecondaryUntil time.Time; BatchSize int; PRs, Subs int; QuarantinedPath string; QuarantinedAt time.Time; PRErrors map[string]string }`. `func (e *Engine) Status() Status` (copy under mu, uses time.Now for SpentLastHour). `func (e *Engine) SetQuarantine(path string, at time.Time)` (called by the dev command after store.Open, D-20).

    engine.go: add the auth fields and the Status-related fields to Engine; nothing else changes.

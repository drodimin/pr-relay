<feature>
  <name>BuildBatch / DecodeBatch</name>
  <files>internal/ghquery/batch.go, internal/ghquery/batch_test.go, testdata/batch-*.json</files>
  <behavior>
    - BuildBatch([a, b], NormalWindow) returns a query that starts with "query PRBatch(", declares $o0,$r0,$n0,$o1,$r1,$n1 and $reviewsLast,$commentsLast,$reviewCommentsFirst as non-null, contains "pr0: repository(owner: $o0, name: $r0)" and "pr1: ...", contains "viewer { login }" and "rateLimit {", contains exactly one "fragment PRFields", and vars == {o0:a.Owner, r0:a.Repo, n0:a.Number, ..., reviewsLast:20, commentsLast:30, reviewCommentsFirst:30}
    - The owner string never appears inside the query text (variables only), even for owner "evil){x}" style input, because BuildBatch rejects any !Valid ref with an error
    - BuildBatch(nil) and BuildBatch(21 refs) return errors; duplicate refs return an error
    - WideWindow gives 100/100/100
    - DecodeBatch(batch-basic.json, [a,b]) gives Viewer "drodimin", RateLimit.Cost set, two Items with Err nil, Snapshot.Ref equal to the requested ref, in request order
    - DecodeBatch(batch-not-found.json): pr1 has `{"pullRequest": null}` (or repository null) plus an error with path ["pr1","pullRequest"] → Items[1].Err is ErrNotFound (errors.Is), Items[0] decoded
    - DecodeBatch(batch-forbidden-nested.json): error path ["pr0","pullRequest","statusCheckRollup",...] → Items[0].Err nil, Items[0].Warnings has one entry starting "FORBIDDEN:"
    - Alias-level FORBIDDEN with null data (path ["pr0"] or ["pr0","pullRequest"] and type FORBIDDEN) → Items[0].Err is ErrForbidden
    - DecodeBatch(batch-rate-limited.json) (errors with type RATE_LIMITED, data null) → returns a *BatchError that errors.Is(ErrRateLimited)
    - An error without a path and no data → *BatchError with the joined messages
    - A returned snapshot whose URL parses to a different ref than requested (case-insensitive compare of owner/repo, exact number) → that alias Err non-nil (mismatch)
  </behavior>
  <implementation>
    `type Window struct { ReviewsLast, CommentsLast, ReviewCommentsFirst int }`; `var NormalWindow = Window{20, 30, 30}`; `var WideWindow = Window{100, 100, 100}`; `const MaxBatch = 20`.

    `func BuildBatch(refs []model.PRRef, w Window) (string, map[string]any, error)`: validate 1..MaxBatch refs, each Valid, no duplicates (compare lower-cased String()). Build with strings.Builder: header `query PRBatch(` + for i: `$o<i>: String!, $r<i>: String!, $n<i>: Int!, ` + `$reviewsLast: Int!, $commentsLast: Int!, $reviewCommentsFirst: Int!) {`, then `rateLimit { cost limit remaining used resetAt nodeCount }`, `viewer { login }`, per i `pr<i>: repository(owner: $o<i>, name: $r<i>) { pullRequest(number: $n<i>) { ...PRFields } }`, closing brace, newline, Fragment. Aliases are generated from the index only.

    `type AliasResult struct { Ref model.PRRef; Snapshot model.Snapshot; Warnings []string; Err error }`, `type BatchData struct { Viewer string; RateLimit RateLimit; Items []AliasResult }`, `var ErrNotFound = errors.New("ghquery: pull request not found")`, `var ErrForbidden = errors.New("ghquery: pull request not accessible")`, `var ErrRateLimited = errors.New("ghquery: rate limited")`, `type BatchError struct { Types []string; Messages []string }` with Error() and `Is(target error) bool` true for ErrRateLimited when any type is RATE_LIMITED.

    `func DecodeBatch(data []byte, refs []model.PRRef) (BatchData, error)`: unmarshal `{ data: map[string]json.RawMessage, errors: []GraphQLError }`. Decode rateLimit and viewer from data if present. Partition errors: path empty or type RATE_LIMITED → batch-level; path[0] == "pr<i>" → alias i. If any batch-level error and data has no prN keys → return BatchError. For each i: raw := data["pr<i>"]; unmarshal into `struct{ PullRequest *wirePR }` (null repository → nil); if nil PR: Err = ErrForbidden when an alias error has type FORBIDDEN, else ErrNotFound (wrap the GraphQL messages with %w); else snapshotFromWire, check ref match, Warnings = errorMessages(alias errors). Response size limiting is ghclient's job (02-07), note it in the doc comment.

    Fixtures are composed from synthetic-basic.json's pullRequest object (bodies "" only): batch-basic (2 aliases, viewer drodimin), batch-not-found (pr1 null + path error), batch-forbidden-nested (pr0 data + nested FORBIDDEN), batch-rate-limited (data null, RATE_LIMITED error). Body hygiene: reuse badBodies from fixtures_test.go in a TestBatchFixturesHaveNoBodies.
  </implementation>
</feature>

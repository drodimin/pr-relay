| Boundary | Description |
|----------|-------------|
| CLI -> daemon control socket | Same-user CLI requests carry deadlines; the daemon must not act on a request after its caller gave up |
| daemon -> state.json | Persisted state must match what the CLI reported |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Repudiation/Integrity | SubscribeVerified commit | mitigate | ctx.Err() re-check under e.mu before mutateLocked; a failed CLI result never leaves a stored subscription |
| T-05-02 | Denial of Service | pollRefs / PollNow | mitigate | lockPoll(ctx) select on ctx.Done() bounds every wait by the caller deadline |
| T-05-03 | Spoofing (false prompt) | subscribeIn lifecycle | mitigate | withoutCheckins + CheckinAt reset so agents never receive a false "still needed?" prompt after renewing |

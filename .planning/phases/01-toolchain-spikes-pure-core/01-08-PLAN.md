<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| spike scripts → herdr socket | Text sent via agent.prompt is typed into a live terminal |
| executor pane (default session) ↔ prspike session | Must never cross: the default session runs the executor and the user's real agents |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-34 | Tampering | spikes/lib.sh (prompt sent to a real agent in the default session) | mitigate | Hard-coded prspike socket path. guard_socket checks `/sessions/prspike/`. guard_target verifies the pane in prspike's agent list. Every call goes through the `hr` wrapper. HERDR_SESSION and HERDR_PANE_ID are unset. The script refuses to run inside a herdr pane |
| T-01-35 | Elevation of Privilege | payload landing in a shell | mitigate | Every payload is prefixed `# pr-relay spike:`, so it is a shell comment |
| T-01-36 | Denial of Service | `herdr session stop` killing the executor or user agents | mitigate | Stop is only ever an instruction to the human, naming prspike explicitly. The script never runs it (acceptance grep) |
| T-01-37 | Information Disclosure | evidence logs in a public repo | mitigate | spikes/out/ is gitignored (01-01). Only redacted excerpts go into 01-SPIKES.md, with a token/path grep in acceptance |
| T-01-38 | Elevation of Privilege | setsid probe left running | mitigate | The child exits after 15 minutes. The binary is gitignored |
</threat_model>

| Boundary | Description |
|----------|-------------|
| dev machine → GitHub | gh token used for repo creation and push |
| GitHub Actions runner → repo | CI workflow executes repo code with GITHUB_TOKEN |
| Homebrew → dev machine | go and gh binaries from homebrew-core |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Elevation of Privilege | .github/workflows/ci.yml | mitigate | Top-level `permissions: contents: read`. No secrets used. pull_request (not pull_request_target) trigger, so fork PRs get a read-only token |
| T-01-02 | Tampering | GitHub Actions dependencies | mitigate | Only official actions (actions/checkout@v7, actions/setup-go@v7, golangci/golangci-lint-action@v9) pinned to major tags. Versions verified in RESEARCH |

| T-01-SC | Tampering | brew install go gh | accept | homebrew-core official formulae (not a package-registry install). No Go modules are added, so the legitimacy audit table is empty per RESEARCH |
</threat_model>

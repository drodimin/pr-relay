  <action>
    `type Options struct { Engine Engine; Dial herdr.DialFunc; Logger *slog.Logger; Now func() time.Time; QuietPeriod, RestoreGrace time.Duration; MaxBytes int; Resync time.Duration }` (Resync default 60s; QuietPeriod default config.DefaultQuietPeriod; RestoreGrace default 10s; Dial default herdr.DialUnix). `func New(o Options) (*Manager, error)` (nil Engine is an error). `func (m *Manager) Run(ctx context.Context) error` with a single-run guard.

    State (owned by the Run goroutine, no shared mutation except via channels): `endpoints map[string]*epState` keyed by `filepath.Clean(socket)` where epState holds the `*herdr.Endpoint`, its cancel func, and its `*herdr.Client`; `workers map[poller.PaneRef]*workerState` (worker, cancel, done channel). Run loop: `start := now`; call `sync()`; then select on ctx, `Engine.PendingWake()`, a Resync ticker, a merged events channel (one forwarding goroutine per endpoint that tags each herdr.Event with its socket), and a worker-exited channel; each branch then calls `sync()` where relevant.

    `sync()`: list subs; group panes by cleaned socket; for each socket without an endpoint, create one (`herdr.NewEndpoint` with the manager's Dial/Logger/Now), start its Run in a goroutine with a child ctx; call `SetPanes(sorted pane ids)` when the set changed; for sockets with no subs, cancel and remove the endpoint and clear reachability (`SetPaneReachability(p, time.Time{})`) for panes no longer subscribed. For each pane with pending events or a drop marker (via Engine.Pending) and no running worker, start a worker with the endpoint's client and the endpoint as its link, `report` = `Engine.SetPaneReachability`. For panes on a socket whose endpoint is down and that have no worker, call `SetPaneReachability(pane, downSince)` where downSince is the endpoint's DownSince (manager start for sockets never connected); clear it when the endpoint is up and no worker reports otherwise.

    Event routing per (socket, event): `KindPaneClosed` -> `Engine.Cancel(id, poller.ReasonPaneClosed)` for every sub on (socket, PaneID) and stop that pane's worker (authoritative event, Pitfall 6 exception). `KindPaneMoved` whose PreviousPaneID is subscribed on that socket -> cancel those subs with `poller.ReasonPaneGone` (per the locked user decision: a move is pane gone; no Repoint, RESEARCH Pattern 8 not implemented). `KindTabClosed` / `KindWorkspaceClosed` -> for each subscribed pane on that socket, spawn a bounded check (one goroutine per pane, result back over a channel) that calls PaneGet and, if CodePaneNotFound and the endpoint has been up for at least RestoreGrace, cancels with ReasonPaneGone (A7 fallback). `KindAgentStatusChanged`, `KindAgentDetected`, `KindPaneExited` -> poke that pane's worker if running. `KindReconnected` -> poke every worker on that socket and run sync (reconcile: workers re-run agent.get; push-time pane.get handles panes closed while disconnected, LIFE-04). `KindDisconnected` -> run the reachability update for that socket. Log cancellations nowhere else (Engine.Cancel logs, D-17); log endpoint up/down at Info.

    On ctx done: cancel all workers and endpoints, wait for their goroutines, return nil.

    Tests in manager_test.go per behavior, using fakeEngine (extend it with `removeSub` and a PendingWake poke on removal if needed).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| daemon -> agent pane (agent.prompt) | Text is typed into whatever process occupies a pane |
| herdr status reports -> gate | herdr's view of agent status decides when typing happens |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-20 | Elevation of Privilege (typing into a shell) | worker gate | mitigate | Prompt only when agent.get reports idle/done for a recognised agent; unknown, launch_pending and agent_not_found never prompt (TestNeverPrompt*); herdr itself refuses agent.prompt on non-agent panes |
| T-03-21 | Spoofing / Information Disclosure (wrong recipient) | identity check | mitigate | D-13 checkIdentity before every prompt and again after the quiet window; mismatch cancels; terminal_id and focused never trusted |
| T-03-22 | Tampering (prompt injection) | deliver text | mitigate | Text comes only from compose/render (sanitized); worker never builds strings from herdr or GitHub data |
| T-03-23 | Denial of Service (hot loop) | quiet period | mitigate | Timer plus signal channel while idle; agent.wait only for working/blocked with timeout_ms; TestQuietNoHotLoop bounds calls per window |
| T-03-24 | Repudiation / data loss | ack ordering | mitigate | AckMany only after prompt success or post-submit timeout; every other outcome keeps the queue (D-05) |
| T-03-25 | Information Disclosure (logs) | delivery logs | mitigate | Prompt text logged only at Debug; Info logs carry counts, pane, socket |
</threat_model>

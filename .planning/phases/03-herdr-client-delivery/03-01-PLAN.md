## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| state.json on disk -> daemon | A file written by an older binary (or edited by the user) is decoded at startup |
| config.toml -> daemon | User-edited config is decoded and validated |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | store.migrate | mitigate | Migration only rewrites the version key; unknown versions keep returning the existing error; newer versions refuse to open (TestStoreNewerVersion) so data written by a newer binary is never truncated |
| T-03-02 | Denial of Service | config quiet_period | mitigate | Validate bounds quiet_period to [1s, 5m] so a zero value cannot create a hot gate loop and a huge value cannot stall delivery forever |
| T-03-03 | Information Disclosure | Subscription.AgentKind | accept | Agent kind is a local herdr label (e.g. "claude"), stored in a 0600 state file that already holds pane ids |
</threat_model>

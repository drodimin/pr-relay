<interfaces>
Verified herdr 0.9.5 / protocol 22 wire shapes (from `herdr api schema --json` and RESEARCH Wire Facts):
- Request line: `{"id":"<string>","method":"<m>","params":{...}}` + newline. Response: `{"id":..,"result":{"type":"<t>",...}}` or `{"id":..,"error":{"code":..,"message":..}}`. The server closes the connection after ONE response.
- `agent.get` params `{"target":"<pane_id>"}` -> result `{"type":"agent_info","agent":AgentInfo}`
- `agent.wait` params `{"target","until":[status...],"timeout_ms":N}` -> `{"type":"agent_info","agent":AgentInfo}`; error `timeout` when timeout_ms elapses; `agent_not_running` when the pinned occupant goes away; no timeout_ms blocks forever
- `agent.prompt` params `{"target","text","wait":{"until":[...],"timeout_ms":N}|null}` -> `{"type":"agent_prompted","agent":AgentInfo}`; `agent_blocked` when blocked (nothing typed); `agent_not_found` on a bare shell or a missing pane
- `pane.get` params `{"pane_id"}` -> `{"type":"pane_info","pane":PaneInfo}`; `pane_not_found` when missing; on a bare shell returns pane_info with `agent_status:"unknown"` and no agent
- `pane.list` params `{"workspace_id":null}` -> `{"type":"pane_list","panes":[PaneInfo...]}`
- `ping` -> `{"type":"pong","version":"0.9.5","protocol":22,"capabilities":{...}}`
- agent.* on a missing pane return `agent_not_found`, never `pane_not_found`
- AgentInfo fields used: `agent` (kind), `agent_session` (object `{source,agent,kind,value}` or null), `agent_status` (idle|working|blocked|done|unknown), `state_change_seq` (uint, default 0), `completion_seq` (nullable uint), `terminal_id`, `pane_id`, `tab_id`, `workspace_id`, `focused`, `launch_pending`, `interactive_ready`. PaneInfo fields used: `pane_id`, `tab_id`, `workspace_id`, `agent`, `agent_session`, `agent_status`, `terminal_id`.
- Error codes: agent_not_found, agent_not_running, agent_blocked, agent_prompt_stalled, pane_not_found, tab_not_found, timeout, invalid_request, events_lost.

Analog: internal/ghclient/client.go (Options + New with discard logger default, transport errors -> typed transient error, `ghclient:` error prefix), internal/ghclient/errors.go (struct errors with Error/Unwrap).
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| daemon -> herdr socket path | The socket path comes from a stored subscription (captured at sub time) and is dialed by the daemon |
| herdr responses -> daemon | JSON lines from herdr are decoded into typed structs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04 | Spoofing / Elevation | herdr.DialUnix | mitigate | Lstat the path; require ModeSocket and Stat_t.Uid == os.Getuid() before dialing; otherwise fail closed as unreachable. Tested with a regular file, a directory and a missing path |
| T-03-05 | Denial of Service | Client.Call read | mitigate | Per-call deadline (5s default, wait timeout + 5s), ctx cancel closes the conn, maxLine 4 MiB bound on a response line |
| T-03-06 | Tampering | response decoding | mitigate | Typed structs with explicit tags; malformed JSON returns a decode error; pane ids are only echoed back to herdr, never rendered into messages |
| T-03-07 | Information Disclosure | logging | mitigate | Call logs method, socket and duration at Debug only; params (prompt text) are never logged |
| T-03-SC | Tampering | package installs | accept | No new dependencies; stdlib only (RESEARCH Package Legitimacy Audit: none) |
</threat_model>

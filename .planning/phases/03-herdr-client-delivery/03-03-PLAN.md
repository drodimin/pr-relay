<objective>
Build the pure message-composition layer: `render.Each`/`DroppedLine`/`HeldLine` in the existing renderer, and a new pure `internal/compose` package that applies the DLV-07 supersede rules, coalesces every pending event of one pane into a single prompt text (DLV-04), applies the D-12 flood guard and computes per-subscription acks.

Purpose: The "terse messages are the product" rule makes this golden-tested core the right place to fix exactly what an agent reads. It has no I/O and no clock, so it runs in Wave 1 next to the herdr client.
Output: render helpers plus `internal/compose` with fixture and golden tests.
</objective>

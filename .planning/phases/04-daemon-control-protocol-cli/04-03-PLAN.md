<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local process → control socket | Any process able to connect can drive subscriptions into the user's panes |
| socket dir on shared /tmp (Linux fallback) | Another local user could pre-create or symlink the dir |
| request bytes → server decoder | Untrusted size and shape |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-10 | Elevation of privilege | control socket | mitigate | ensurePrivateDir: dir 0700, Lstat no-symlink, uid owner; socket chmod 0600 (daemon, 04-10) |
| T-04-11 | Tampering | /tmp/pr-relay-<uid> fallback | mitigate | refuse symlink or foreign-owned dir with "unsafe socket dir" |
| T-04-12 | Spoofing | client dial target | mitigate | ctl.DialUnix requires ModeSocket and owner uid == current uid |
| T-04-13 | Denial of service | server read | mitigate | MaxLine 1 MiB cap, 5s read deadline, per-method handler timeouts |
| T-04-14 | Tampering | version skew executes wrong schema | mitigate | daemon-side gate refuses non-exempt methods before dispatch; hello/shutdown frozen |
| T-04-15 | Information disclosure | server logs | mitigate | log method and error code only, never params or results |
</threat_model>

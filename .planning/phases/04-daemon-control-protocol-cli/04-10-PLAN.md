<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| control socket → handlers | Requests from any same-user process (agents may be prompt-injected) |
| daemon → herdr socket named in a request | Daemon dials a path supplied by the CLI |
| daemon → filesystem (socket, pid, lock) | Paths in shared temp fallback |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-37 | Elevation of privilege | socket access | mitigate | socket chmod 0600 inside 0700 dir verified by paths.ensurePrivateDir (04-03) |
| T-04-38 | Tampering | stale-socket removal | mitigate | remove only after holding the socket lock and only if Lstat reports ModeSocket; other types refused |
| T-04-39 | Spoofing | crafted HerdrSocket in a request | mitigate | absolute path required; herdr.DialUnix refuses non-socket or foreign-owned paths (T-03-04) |
| T-04-40 | Tampering | malformed params | mitigate | strict decode into fixed structs; ParsePRLink + normalizeMask re-validate daemon-side |
| T-04-41 | Denial of service | cross-pane wipe | mitigate | unsub scoped to the request's socket+pane; reset requires CLI --yes/TTY (04-11) |
| T-04-42 | Information disclosure | logs | mitigate | log method, code, PR key, pane id only; no tokens or PR text; file 0600 |
| T-04-43 | Denial of service | old daemon unlinks new socket on restart | mitigate | strict shutdown order (listener before store and lock); 10x restart test |
</threat_model>

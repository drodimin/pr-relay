| agent CLI arg → model.ParsePRLink | Untrusted link text from an agent (possibly prompt-injected) |
| config.toml → config.Load | User-edited file |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | ParsePRLink | mitigate | Normaliser always ends in strict ParsePRURL (rejects ports, userinfo, traversal, bad names); host must equal github.com after lower-casing |
| T-04-02 | Spoofing | ParsePRLink host check | mitigate | Reject look-alike hosts (github.example.com, github.com:8443) with "only github.com is supported" (DMN-08); table tests cover them |
| T-04-03 | Tampering | render lifecycle lines | mitigate | Only ref.URL() (validated) and an integer duration are interpolated; fits() guard retained (D-05) |
| T-04-04 | Denial of service | config lifecycle bounds | mitigate | Validate floors (1h) and ceilings (30d/90d) prevent a 1ns check-in flood; fast floors only under EnvFastPoll test env |
</threat_model>
